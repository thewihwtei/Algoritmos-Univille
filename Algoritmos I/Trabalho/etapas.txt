ETAPAS PARA RESOLUÇÃO DA ATIVIDADE

1. Definir as respostas corretas da prova e armazená-las no arquivo gabarito.txt.

2. Criar o arquivo candidatos.txt contendo:
   - ID do candidato
   - Nome do candidato
   - 20 respostas separadas por vírgula

3. Desenvolver um script em Python utilizando listas.

4. Ler o arquivo gabarito.txt e armazenar as respostas corretas em uma lista.

5. Ler o arquivo candidatos.txt e armazenar os dados dos candidatos.

6. Comparar cada resposta do candidato com o gabarito.

7. Somar 1 ponto para cada resposta correta.

8. Armazenar ID, nome e nota em uma lista de classificação.

9. Gerar o arquivo classificacao.txt contendo:
   ID, Nome e Nota.

10. Realizar testes para verificar se as notas foram calculadas corretamente.
